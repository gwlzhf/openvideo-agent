# 配乐模板库

用法：`generate.mjs` 会自动把选中的风格复制为视频工程的 `assets/music/make-music.mjs`（并带上 `audio-kit.mjs`）。
手动运行时，在视频目录执行：
`node assets/music/make-music.mjs assets/music.wav plan.json`（时长和镜头切点都从 plan.json 读，`pipeline.sh` 不会自动生成配乐）。
所有模板统一 120 BPM（一小节 2 秒），镜头起止放偶数秒就能落在小节线上。
全部用 `audio-kit.mjs` 合成（无第三方依赖），同一个 plan 生成的结果可重复。

| 风格 | 文件 | 特点 | 适合 |
| --- | --- | --- | --- |
| 抖音魔性卡点 | `douyin-bounce.mjs` | 重复的拨弦钩子旋律、弹跳低音、四拍底鼓 + 反拍踩镲；每个镜头切点前有上升音效、瞬停、落点重击 | 抖音、视频号竖版，要节奏、要卡点 |
| 轻柔马林巴 | `soft-marimba.mjs` | 低中音区稀疏琶音 + 少量旋律音 + 轻低音，无鼓无上升音效，带高频衰减，不抢人声。**有旁白的视频默认用它** | 带人声旁白的安装介绍、教程 |
| 欢乐颂 | `ode-to-joy.mjs` | 贝多芬《欢乐颂》（公版），琶音伴奏，结尾淡出，不卡点 | 想要熟悉、舒缓的曲子，B 站横版 |
| 少数民族乐器 | `ethnic-pentatonic.mjs` | 全部用 A 小调五声音阶（羽调）：拨弦琶音（冬不拉 / 热瓦普 音色）、气声笛子长音（笛子 / 葫芦丝 音色）、马头琴式低音持续音，无鼓，不抢人声 | 带旁白的民族风、文化类、横版或竖版皆可 |

注：最早那首“柔和轻快”（拇指琴琶音 + 钟琴）的脚本已丢失，`soft-marimba` 是按同样思路重写的替代版。

新增风格：复制一份模板改旋律 / 和弦 / 鼓型，文件名用风格名（`.mjs`），导入 `./audio-kit.mjs` 并在上表加一行。
